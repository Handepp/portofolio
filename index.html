Linear Position Tracking System using Rotary Encoder
Embedded System

Project Overview

This project is an embedded system designed to track linear rail position accurately using a rotary encoder. The movement data is synchronized with interactive content, allowing real-time position-based interaction.

Role & Contribution

Developed the embedded firmware, encoder reading logic, ESP32 communication flow, and system integration for position tracking.

Technologies Used

Embedded C ESP32 Rotary Encoder Bluetooth EasyEDA

Project Details

  • Reads rotary encoder pulse data to calculate linear displacement.
  • Uses ESP32 as the main controller.
  • Synchronizes movement data with external interactive content.
  • Designed for reliable real-time position tracking.
